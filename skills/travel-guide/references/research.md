# 事实采集清单

写正文前把这些查齐。**没有把握的项不要猜，直接标"以现场 / 当日公告为准"，并写进清单的"出发前复核"一节。**

## 1. 骨架参数

- 出发地 → 目的地、日期与总天数、落地与返程的航班 / 车次时刻
- 人数与关系（影响房型：几间房、几对情侣、能否拼车 / 拼房）
- 交通方式：自驾 / 包车 / 公共交通 / 混合；自驾还要问车型与是否异地还车
- 强度：每天能开几小时、能不能早起、要不要徒步
- 明确不去的地方、必须去的地方、预算上限

## 2. 交通与路况

- 各段里程与**区间车程**（写"约 190 km / 3.5–4 h"，别写"半天"）
- 加油：服务区间隔、进山前最后一个加油站、油品（高原 / 偏僻地区常无 95#）
- 检查站、限速、区间测速、隧道与盘山段、夜间禁行
- 收费：过路费大致水平、景区停车费、限行或单双号
- 备用路线：主路何时会封（大风 / 沙尘 / 暴雪 / 塌方），绕行方案多花多少时间

## 3. 许可、证件与预约（最容易翻车的一类）

- 是否需要边防证 / 通行证 / 入区许可；办理渠道（App / 小程序 / 政务大厅）、是否免费、有效期、是否现场停办
- 是否限流：每日车辆配额、实名预约、提前几天放号、抢不到怎么办
- 门票实名绑定方式、有效期（有的门票多日多次进出）、退改规则
- 特殊人群：外籍 / 港澳台是否可办、儿童与老人政策
- 无人机、拍摄设备、专业器材是否需报备

## 4. 时刻表与开放时间

- 景区开放与**停止售票**时间（旺季 / 淡季两套，且 10 月后常提前收）
- 区间车 / 索道 / 轮渡的首末班，**末班回程**尤其要单独确认
- 换乘中心发车间隔、换乘次数（几次检票、在哪检）
- 摆渡车是否另行收费、是否只走单程

## 5. 门票与体验项目

- 门票 + 区间车 + 专线 + 保险的**分项价格**，以及"联票 vs 单买"哪个划算
- 体验项目：骑马 / 游船 / 直升机 / 温泉 / 演出——价格区间、时长、起止时间红线、雨雪是否停运、是否含向导
- 优惠政策（学生 / 老年 / 军人 / 当地身份证）

## 6. 住宿

- 住景区内 vs 景区门口 vs 县城的取舍（价格 / 看日出日落 / 次日时间 / 行李搬运）
- 旺季价格区间与"最紧的一晚"，哪个必须先锁
- 停车位置与是否禁自驾进村、能否寄存行李、能否代订清晨车辆
- 热水、供暖、独卫、含早这些在偏远村寨要逐项确认
- 统一策略：能免费取消的优先——这是启用降级方案的前提

## 7. 天气、光线与季节

- 同期常年气候（近 5 年经验值即可，但**必须标明是参考不是预报**）
- 关键景点的日出 / 日落时刻（±10 分钟），以及"最佳光线窗口"（例如晨雾最浓在日出后 30–60 分钟）
- 哪些点位依赖晴天 / 无风 / 无雨，标成 ★ / ★★ / ★★★ 需晴等级
- 温差与体感：几点出发要穿到什么程度（"清晨 -4℃，穿最厚一层"）
- 精确预报的复核时点（出发前 3 天起逐日看）

## 8. 餐饮

- 每个落脚点的特色与**具体店铺 / 街区**（夜市名、市场名），不要只写"当地美食"
- 人均价格、营业时间（新疆 / 西北很多店 20:00 后才是饭点）
- 需不需要提前订（民宿晚餐、烤全羊、景区内餐厅）
- 供给短板：景区里补给少、村内物价高一档——要把"在哪买齐"写清楚

## 9. 风险与预案

为每种"会打乱行程的事"准备一句可执行动作，而不是"注意安全"：

- 天气：大风 / 沙尘 / 雨雪 / 大雾各自砍什么、保什么、推迟多久出发
- 停运：区间车停运、马队停运、索道检修、演出取消
- 身体：高原反应、晕车、长途驾驶疲劳（双司机轮换节奏）
- 拥堵：国庆 / 暑期排队点、错峰到达时间

## 10. 降级方案（可选但很值）

当某一段强烈依赖天气（沙漠公路、环湖公路、山路）时，写一版整段替换的"降级包"：每天改去哪、住哪、多开多少公里、酒店怎么改订、什么时候做决定。
