# 章节骨架与文风

八章是默认骨架，按目的地增删，但**前四章和最后一章基本不能省**（行程总览、天气光线、预订住宿、逐日计划、行前清单）。

## 封面

`.kicker` 一句话版本说明 → `h1` 主标题（路线 + 天数）→ `.subtitle` 人群与定位 → `.chain` 整条路线一行画完（**每个"过夜点"加粗并标日期**）→ `.meta-grid` 八格关键参数（日期 / 返程 / 天数 / 人数车辆 / 版本 / 行程方式 / 总里程 / 文档日期）→ 目录表 → `.note` 写"本版相对上一版的变化"。

路线一行（`.chain`）是全篇最该打磨的东西：读一遍就知道每天在哪、换几次基地。

## 一、行程总览与路线图

- 1.x 地图 / 路线示意：**内联 SVG**，标出过夜点、关键里程、方位关系。别引外部地图图片。
- 逐段里程 / 车程总表
- 基地安排：这一趟有几个"基地"、各住几晚、哪些天不动车（把行李寄存在哪）
- **红线表**：错过就麻烦的时点（末班车、上马时间、停止入园、还车时间），每条给"后果"和"补救"

## 二、天气与光线速查

- 逐日表：日期 / 天气要点 / 需晴等级（★–★★★）/ 日出日落 / 备注
- 明确写"这是常年同期参考，不是预报"，并给出复核节奏（出发前 3 天起每天 3 分钟）

## 三、预订 · 门票 · 酒店

- 门票表：项目 / 价格 / 关键规则（含"单买还是联票划算"的结论）
- **预算小计**：人均门票、整体预算区间（分租车、住宿、门票、餐饮、杂项）
- 住宿表：**按紧张程度排序**，不是按日期排序，并给出"选房要点"
- 收尾 `.warn`：今晚就该做的 3–4 件事

## 四、逐日计划

每天一个 `.day` 卡片：

```html
<div class="day">
  <div class="dhead"><span class="dt">D3 · 9/29（周二）</span><span class="rt">一句话主题</span></div>
  <div class="dmeta"><b>里程</b> …　<b>车程</b> …　<b>天气</b> ★★★ …　<b>宿</b> …</div>
  <div class="bd">
    <table class="t">…时间 / 安排与细节…</table>
    <div class="warn">…红线与纪律…</div>
    <div class="opt">…不这样走行不行…</div>
  </div>
</div>
```

- 时间列用 `td.time`，粒度 15–45 分钟，留出弹性且**说明弹性在哪**
- 当天有机位 / 日落 / 晨雾时，用 `span.sun` 标出窗口
- 危险或不可错过的用 `span.red`
- 傍晚必须写"今晚几点睡、明早几点起"，把连续几天的作息串起来

## 五、吃喝地图

按落脚点排：地点 / 怎么吃（点名的街区与菜品）/ 人均 / 点单提醒。结尾加购物与手信一行。

## 六、景区关键情报

一个景区一小节，只写**会改变决策**的信息：怎么进、门票与换乘、最佳顺序与用时、必看 vs 可跳、容易踩的坑（检票点、方向坐错、末班时刻）。

## 七、弹性预案

- 优先级三分：保底必去 / 可压缩 / 可放弃
- 分场景天气预案表：场景 → 可执行动作
- 强依赖天气的段落给"降级包"（整段替换后的逐日安排 + 代价 + 启用时点）
- "常见取舍的答案"：把用户问过的问题写进去（"值不值""够不够""放哪天"）

## 八、行前清单与资料说明

- 出发前 48 小时清单，按类别（证件 / 票务 / 车辆 / 衣物 / 电子 / 健康 / 其他）
- 资料与数据说明：价格依据年份、里程口径、哪些是参考值、生成日期与版本含义

`.foot` 页脚：版本号 + 路线一句话 + 祝福。

## 文风

- 中文，短句，第二人称（"你"或直接命令式），不用广告腔
- **能用表格就不用段落**；段落只用于解释"为什么"
- 关键结论加粗；风险用红色；价值点用橙色
- 给数字、给时刻、给价钱、给公里数
- 每一节结尾尽量落到"所以你要做什么"
- 允许口语化的判断句（"这一段是本行程最值钱的徒步"），但事实部分必须准确

## 打印排版注意

- `.chapter` 自动分页；`.day` 卡片避免跨页断裂
- 表格行 `page-break-inside: avoid`，表头 `display: table-header-group` 让长表跨页时重复表头
- 正文 9.2–9.6pt、行高 1.5 左右，A4 页边距 12–15mm——目标是最少页数下仍然能看清
